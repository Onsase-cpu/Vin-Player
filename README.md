# VinPlayer v2

A lightweight **Version 2 improvement of VinPlayer**, building upon the foundation established by **VinPlayer v1**, an audio player platform designed to support a wide range of audio formats and provide users with a simple way to manage and enjoy their local music.

VinPlayer v2 focuses on delivering a **cleaner, lighter, and more refined audio playback experience**, with improvements to the user interface, usability, responsiveness, and overall application structure.

## About VinPlayer

VinPlayer is a modern audio player designed for users who want a straightforward way to play and manage audio files directly from their devices. The project prioritizes **simplicity, accessibility, performance, and a minimal user experience** without unnecessary complexity.

Version 2 continues the original vision while introducing a more polished interface and improved functionality compared with the first release.

## What's New in Version 2

VinPlayer v2 introduces improvements including:

* Improved and cleaner user interface
* Lightweight application design
* Better audio playback controls
* Support for multiple audio file types
* Local audio file selection from the user's device
* Improved responsiveness across different screen sizes
* Refined navigation and user interaction
* More organized player layout
* Improved overall usability and visual consistency
* Foundation for future VinPlayer features and releases

## Core Features

* **Audio Playback** — Play supported audio files directly from your device.
* **Local File Selection** — Select and load music stored locally on your computer or device.
* **Playback Controls** — Play, pause, skip, seek, and control audio playback.
* **Volume Control** — Adjust audio volume directly from the player.
* **Responsive Interface** — Designed to remain usable across different screen sizes.
* **Lightweight** — Built with performance and simplicity in mind.
* **Minimal Design** — A clean interface focused on the music rather than unnecessary visual clutter.

## Version History

### VinPlayer v1

The original VinPlayer release established the project as a lightweight audio player capable of supporting a variety of audio types and providing basic local audio playback functionality.

### VinPlayer v2

Version 2 builds on that foundation with a more refined interface, improved usability, cleaner organization, and a stronger focus on delivering a lightweight modern audio-player experience.

## Project Goals

The long-term goal of VinPlayer is to develop a practical and accessible media-player ecosystem that gives users greater control over their locally stored media while maintaining a **simple, fast, and user-friendly experience**.

Future versions may expand the project with additional playback capabilities, playlist management, metadata support, media-library organization, customization options, and other improvements.
